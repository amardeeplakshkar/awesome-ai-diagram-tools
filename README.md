# 📐 Awesome AI Diagram Tools

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re) [![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md) [![License: CC0-1.0](https://img.shields.io/badge/License-CC0--1.0-lightgrey.svg)](LICENSE) ![Entries](https://img.shields.io/badge/Entries-20-blue.svg)

A curated list of AI diagram tools for architecture diagrams, flowcharts, ER diagrams, sequence diagrams and diagram as code workflows.

## Why This List

AI coding agents can now draw useful diagrams from prompts, code, schemas and docs. This list collects simple AI diagram tools, agent skills, diagram as code tools and canvas apps that help developers explain systems faster. Each entry is one line: name, what it does, and link.

## Agent Diagram Skills

| Tool | What it does |
| --- | --- |
| [Archify](https://github.com/tt-a1i/archify) | Turns an idea, plan or codebase into an interactive diagram or one-page answer for coding agents. |
| [Diagram Design](https://github.com/cathrynlavery/diagram-design) | Agent skill for branded HTML and SVG diagrams in many editorial styles. |
| [drawio-skill](https://github.com/Agents365-ai/drawio-skill) | Turns prompts, code, Terraform, SQL and OpenAPI into editable draw.io diagrams. |
| [Next AI Draw.io](https://github.com/DayuanJiang/next-ai-draw-io) | Chat with AI to create and edit draw.io diagrams on a real canvas. |
| [SVG Diagram](https://github.com/bybit-exchange/svg-diagram) | Agent skill and linter for consistent hand-placed SVG diagrams. |
| [QGraphFlow](https://github.com/supermax92/qgraphflow) | Builds evidence-backed interactive software diagrams from code, schemas and requirements. |

## Code and Schema Diagrams

| Tool | What it does |
| --- | --- |
| [vibeX](https://github.com/Raja0sama/vibex) | Generates ERD, C4, API and lifecycle diagrams from Prisma, OpenAPI, GraphQL or source code. |
| [SeeCode](https://github.com/Aryanutkarsh/SeeCode) | Turns a short JSON spec into animated, explorable diagrams for coding agents. |
| [Diagrams](https://github.com/mingrammer/diagrams) | Python diagram as code for cloud architecture diagrams with provider icons. |
| [DrawDB](https://github.com/drawdb-io/drawdb) | Browser editor for database ER diagrams with SQL import and export. |
| [LikeC4](https://github.com/likec4/likec4) | C4 as code toolkit for architecture models and generated views. |

## Diagram as Code

| Tool | What it does |
| --- | --- |
| [Mermaid](https://github.com/mermaid-js/mermaid) | Markdown-like text for flowcharts, sequence diagrams, ER diagrams and more. |
| [D2](https://github.com/terrastruct/d2) | Modern diagram scripting language that turns text into SVG diagrams. |
| [PlantUML](https://github.com/plantuml/plantuml) | Text-based UML and architecture diagrams with many diagram types. |
| [Graphviz](https://graphviz.org/) | Graph layout engine for DOT diagrams and generated graph images. |
| [Kroki](https://github.com/yuzutech/kroki) | One API that renders many diagram languages to SVG, PNG or PDF. |

## Canvas and AI Diagram Apps

| Tool | What it does |

| [Excalidraw](https://github.com/excalidraw/excalidraw) | Open-source hand-drawn whiteboard for diagrams and wireframes. |
| [tldraw](https://github.com/tldraw/tldraw) | Infinite canvas SDK for building diagram and whiteboard apps. |
| [Eraser](https://www.eraser.io/product/ai-diagrams) | AI diagram generator for architecture, flowcharts, ERDs and sequence diagrams. |
| [Napkin AI](https://www.napkin.ai/) | Turns text into editable diagrams, flowcharts, mind maps and infographics. |
